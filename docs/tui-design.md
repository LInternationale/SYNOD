# TUI 设计准则

## 页面、标题和焦点

全屏页面使用独立标题行，标题加粗并使用当前主题色. 标题下一行绘制横贯内容宽度的主题色分割线，正文从第三行开始. 页面保持无外框. 工作区文件树可以有无标题边框，提示框的标题独立成行.

方向键依照控件的实际方位移动，Tab 和 Shift+Tab 按阅读顺序切换. 所有可点击按钮都可通过键盘到达并按 Enter 激活. Esc 返回上一级，在最外层停留. 界面省略「返回」按钮.

## 按钮、复选框和操作提示

- **必须作出的选择**占满可用操作行. 有多个选项时共同撑满整行，各选项的文字居中.
- **进入可用操作的按钮**从左向右排列，每个宽 12 个半角字符，文字在各自的点击区域内居中. 按钮一律放在倒数第二行，每页最多十个.
- 按钮显示为「快捷键 名称」，按本页操作顺序使用 F1 到 F10. 输入框接受普通数字.
- 未选复选框使用空心方框 □，已选复选框使用当前主题色的实心方框 ■. 焦点与勾选状态分别呈现. 勾选本身产生 Git 提交时，Space 暂存，Enter 提交. 在复选列表中，Space 切换当前项，Enter 声明整组选完.
- 最后一行显示与当前光标位置有关的操作，格式为「按键 · 操作」. 例如光标在子工作区目录上显示「space · 切换同步模式」，在已寄信上显示「r · 快速回复」.

## 编辑与导航

所有可直接输入的栏目均显示插入光标，文字与光标使用可区分的颜色. 首次设置按步骤说明每项选择的用途及后果.

写信时焦点高亮到字段标识符及其留白为止，输入文字保留正文样式，显示颜色可区分的插入光标. 正文标识符独占一行. 滚动正文时保留页面标题、分割线和信件标题，回到正文开头时恢复收件、抄送和引用行.

公告板按「写信、工作区、筛选、偏好」排列. 快速回复依附于光标选中的已寄信. 筛选支持多选，空格切换后立即应用，Enter 完成选择，Esc 可返回公告板. 偏好使用「成员、远端、工作区、风格」四个顶部分页，配置内容直接显示在当前页内.

工作区使用树状连接线，标签目录使用明确标记和主题色. 工作区内按空格切换已有标签的同步模式. 偏好内按「非子工作区 → 仅手动 → 自动 → 非子工作区」循环.

界面中文文案统一以半角句点和空格（U+002E U+0020）断句. 默认主题色为 `#9AB0C2`，用户在「风格」中选择 RGB 并应用后使用新颜色.

进入写信正文时自动开始编辑，方向键移动插入点. Esc 切到阅读模式，方向键和滚轮可以滚动正文. 子任务位于引用下一行. 附件列表接在正文末尾，焦点在附件标题上时按 a 添加，在附件条目上时按 x 删除. 寄信确认页在上方显示摘要，倒数第二行放确认按钮.

信件详情按名册显示发件人、收件人和抄送人的显示名. 抄送下一行显示子任务，可用 Enter 打开复选列表，Space 勾选后按 Enter 完成选择. 再下一行左侧为完成框，有子任务或正文待办时在右侧显示进度条，浅色表示完成，深色表示未完成.

长正文的右侧显示主题色滚动条，滑块表示当前位置和可见比例. 最后一行左侧显示操作提示，右侧显示当前状态. 寄信在本机持久入队后返回公告板，存草稿、保存个人工作与修改信件任务在本机提交后返回界面，推送结果显示在状态栏. 工作区合并等待远端确认.

公告板为每封信预留一个状态字符和一个空格. 寄送中使用旋转盲文，失败草稿使用 `!`，普通草稿使用 `#`，未读来信使用 `*`，已寄及已读信件使用空格. 打开失败草稿后可直接修改，存草稿恢复普通草稿标记，寄信重新入队. 所有页面都可聚焦最下行右侧的当前任务，Enter 打开任务队列，Esc 回到原处.
